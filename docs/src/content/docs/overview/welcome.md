**SurrealDB S3** is a plugin for SurrealDB that enables interfacing with S3 inside
SurrealQL. It speaks the S3 protocol directly, signing and issuing requests against
the configured server on its own.

[Read more about SurrealDB plugins](https://surrealdb.com/docs/learn/extensions/plugins/overview)
in the official SurrealDB docs.

## Features

- Get, put, and delete objects
- Generate pre-signed URIs
- Multipart uploads
